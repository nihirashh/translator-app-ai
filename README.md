# 🌍 EasyTranslate AI
A simple AI-powered web application that translates text into multiple languages in real time.


# Features
* Translate text instantly
* Supports multiple languages (English, Hindi, French, Spanish, German)
* Clean and user-friendly UI
* Fast and lightweight

  
# Tech Stack
* Python (Flask)
* HTML & CSS
* Deep Translator (AI translation)


# 🌐 Live Demo
https://easytranslate-ai.onrender.com/


# Project Structure
```
translator-app-ai/
```

# How to Run Locally
```bash
pip install -r requirements.txt
python app.py
```

# 📌 Note
This project uses an external translation library and demonstrates how AI-based services can be integrated into web applications.
